# KeyAutomator v2.8.6

英語 UI 対応リリースです。Windows の表示言語に合わせて日本語 / English を出し、画面右下から固定もできます。

## 変更内容

- 日本語 / English の UI・ダイアログ・CLI ヘルプ
- 画面右下の言語切替（Windows に合わせる / 日本語 / English）
- 英語のプライバシーポリシー（`PRIVACY.en.md`）
- Microsoft Store 掲載用スクリーンショット（日本語・English、1920×1080）
- zip に `GettingStarted.txt` と `PRIVACY.en.md` を同梱
- 初回サンプル名・確認ダイアログ、`error.log`、例外メッセージも表示言語に合わせる（`config.sample.en.json` を同梱）
- GitHub Release 公開時に Microsoft Store へ Store 用パッケージを自動提出（認定後に反映）
- CLI 用の「起動パスをコピー」、単体テスト隔離、CI の品質ゲート（2.8.5 相当。前回公開は v2.8.4）

## ダウンロード（Release 公開後）

- `KeyAutomator-v2.8.6-win-x64-single.zip` … 単一 exe（推奨）
- `KeyAutomator-v2.8.6-win-x64-msix.zip` … サイドロード用 MSIX

## English

UI, dialogs, CLI help, first-run sample names, error.log, and exception messages follow Windows display language (or a lock in the bottom-right Language box). Privacy policy: `PRIVACY.en.md`. Store listing screenshots are under `docs/microsoft-store/listing-assets/`. English sample JSON: `config.sample.en.json`. Publishing a GitHub Release also submits the Store package to Partner Center (live after certification).
