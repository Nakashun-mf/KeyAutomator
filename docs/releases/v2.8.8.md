# KeyAutomator v2.8.8

Microsoft Store への自動提出が、提出用ディレクトリの渡し方で落ちていたのを直したリリースです。アプリ本体の画面は v2.8.7 と同じです。

## 変更内容

- `msstore publish -i` に `.msix` の親フォルダ（中身は `.msix` / `.msixsym` のみ）を渡す
- blob アップロード待ちを延ばす（`--uploadTimeout 600`）
- v2.8.7 の「パス＋引数をコピー」（テスト実行の右）とフッタの起動パス固定を含む

## ダウンロード（Release 公開後）

- `KeyAutomator-v2.8.8-win-x64-single.zip` … 単一 exe（推奨）
- `KeyAutomator-v2.8.8-win-x64-msix.zip` … サイドロード用 MSIX

## English

Fixes Microsoft Store auto-submit (`msstore publish -i` must be a directory of `.msix` / `.msixsym`, with a longer upload timeout). App UI is unchanged from v2.8.7 (Copy path + args next to Test run).
