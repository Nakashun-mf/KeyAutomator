KeyAutomator 使い方（かんたん版）
================================

【1】置き場所
・Documents\KeyAutomator など「書き込みできるフォルダ」に置いてください
・Program Files には置かないでください（設定が別の場所に保存されます）

【2】起動
・KeyAutomator.exe をダブルクリック
・初回は少し時間がかかることがあります
・はじめて起動すると、サンプルマクロが2件入っています

【3】動かしてみる
1. 左の一覧でマクロを選ぶ
2. 下の「テスト実行」を押す
3. 表示される秒数のあいだに、入力したいウィンドウをクリックして前面にする
4. 自動入力が始まります（途中で止めたいときは「中断」）

【4】自分のマクロを作る
1. 「新規」を押す
2. 名前を付ける
3. 「テキスト」「キー」「ショートカット」などで手順を追加
4. 「保存」を押す

【5】コマンドライン（上級）
・引数名（例: login_ok）を付けて保存すると、次のように実行できます
  KeyAutomator.exe -alias login_ok
  KeyAutomator.exe -login_ok
・確認ダイアログ（確認アクション）は CLI でも画面に出ます

【困ったとき】
・保存先のパスは、画面いちばん下の文字に表示されます
・エラー時は同じフォルダの error.log（または %LocalAppData%\KeyAutomator\error.log）を見てください
・詳しくは README.md / GitHub Releases を参照してください
