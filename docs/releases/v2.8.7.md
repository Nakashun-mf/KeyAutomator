# KeyAutomator v2.8.7

CLI 用の「パス＋引数をコピー」が画面から消えたように見えていた問題を直したリリースです。

## 変更内容

- **テスト実行の右**に **「パス＋引数をコピー」**（英語 UI では `Copy path + args`）を置く
- マクロ選択中は exe パスと `-alias` / `-id` をまとめてコピーする（未選択ならパスだけ）
- 画面下の「起動パスをコピー」は左端に固定し、ステータスや言語コンボで隠れないようにする
- v2.8.6 の英語 UI・Store 自動提出はそのまま含む

## ダウンロード（Release 公開後）

- `KeyAutomator-v2.8.7-win-x64-single.zip` … 単一 exe（推奨）
- `KeyAutomator-v2.8.7-win-x64-msix.zip` … サイドロード用 MSIX

## English

Adds **Copy path + args** to the right of Test run. With a macro selected it copies the exe path plus `-alias` / `-id`. The footer **Copy launch path** button stays pinned on the left so status text and the language box no longer clip it.
