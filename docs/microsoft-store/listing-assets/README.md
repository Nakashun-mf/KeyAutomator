# ストア掲載用アセット

Partner Center の「ストア一覧」に使う画像です。  
**実機の GUI スクリーンショットは Windows 上で撮影**してください（このフォルダには仕様と置き場だけ用意しています）。

## 必須に近いもの

| 種類 | 推奨サイズ | 枚数 | メモ |
|---|---|---|---|
| スクリーンショット | **1920×1080** または **1366×768** | 1 枚以上（3〜4 枚推奨） | PNG/JPEG。実際のアプリ画面 |
| ストアロゴ（一覧） | Partner Center の指示に従う（多くは 300×300） | 1 | パッケージ内 `Assets/StoreLogo.png`（50×50）とは別用途 |

## あると良いもの

| 種類 | サイズ目安 |
|---|---|
| ヒーロー画像 | 2400×1200 など（Partner Center 表示に従う） |
| 追加スクリーンショット | 機能ごと（編集画面／実行イメージ／CLI） |

## 撮影のヒント（KeyAutomator）

1. サンプルマクロが入った状態のメイン画面
2. アクション編集（テキスト＋ショートカットが見える状態）
3. テスト実行前（ウェイト秒数が見える状態）
4. （任意）メモ帳などへ入力した結果のビフォー／アフター

個人情報・実パスワードは写さないでください。

## このフォルダへの配置例

```text
docs/microsoft-store/listing-assets/
  screenshot-01-main.png
  screenshot-02-actions.png
  screenshot-03-testrun.png
  store-logo-300.png
```

画像バイナリはリポジトリに含めなくても構いません（容量が大きい場合）。Partner Center へ直接アップロードでも可。

## パッケージ内アイコン（参考）

アプリタイル用（`Assets/`）は既に scale-200 が揃っています。

| ファイル | 実寸 |
|---|---|
| StoreLogo.png | 50×50（パッケージ用） |
| Square44x44Logo.scale-200.png | 88×88 |
| Square150x150Logo.scale-200.png | 300×300 |
| Wide310x150Logo.scale-200.png | 620×300 |
| SplashScreen.scale-200.png | 1240×600 |

掲載用の 300×300 ロゴを別途用意すると、ストアページの見た目が安定します。
