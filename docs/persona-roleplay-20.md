# ペルソナロープレ 20人（順番実走）

> 以前の「100人」は属性マトリクスの自動集計であり、一人ずつ通したロープレではなかった。  
> 本ドキュメントは **20人を1→20の順に**、GitHub入手から実際の画面・文面を見ながら通した結果。

対象バージョン想定: **v2.7.7**（サンプル投入・使い方.txt 同梱後）

共通ルート:
1. GitHub リポジトリ or 検索で到達
2. Releases から zip DL
3. 解凍・配置
4. 起動
5. 目的に応じて操作（サンプル／新規／CLI）

各人の末尾: `詰まり`（その人固有） / `共通メモ`

## 01. 佐藤恵子（58・市役所事務・IT苦手）

**目的:** 毎日の業務システムログインを楽にしたい。同僚が「GitHubにある」とメモをくれた。

1. ブラウザでリポジトリを開く。「Code」「Issues」ばかりで、どれがダウンロードか分からない。README をスクロールして「最新リリース」リンクを見つける（ここで既に疲弊）。
2. Releases のタイトルが「100人ペルソナ検証」→ **中身のソフトと無関係に見え、不安**。「これ試作？」と思う。
3. Assets の `...win-x64-single.zip`。「自分のPCで動くの？」と迷うが、READMEの説明を思い出してDL。
4. 解凍。`使い方.txt` を見つけて安心。Documents にフォルダを作って置く（使い方通り）。
5. 起動。SmartScreen → 「詳細情報」が分からず一旦閉じる。使い方に一文あるので再挑戦して起動成功。
6. サンプルが2件あって安心。「ログイン&定型…」を選ぶ。
7. 「待ち 3秒」の意味が分からない。ツールチップに気づかず、テスト実行→自分のメモ帳に入力されてしまう。ダイアログの注意文は読んだけど、秒数が短く間に合わず。

**詰まり:** Releases見出しが実験っぽい／SmartScreen／「待ち」ラベルが暗号／切替時間が足りない  
**共通メモ:** 非エンジニアはリポジトリTOPからReleasesに迷う
