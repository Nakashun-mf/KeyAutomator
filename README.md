# KeyAutomator

キー入力シーケンスを登録し、指定秒数待機後にアクティブウィンドウへ自動入力する Windows デスクトップアプリです。

**バージョン:** 1.0.0

## できること

- マクロの登録・編集・削除・複製（GUI）
- テキスト / 特殊キー / ショートカット / ウェイトの組み合わせ実行
- コマンドラインからサイレント実行（画面非表示）

## 動作環境

- Windows 10 / 11（64bit）
- 配布用 exe は単体で動作（.NET ランタイムの別途インストール不要）

## 使い方（利用者向け）

### GUI で管理する

1. `KeyAutomator.exe` をダブルクリックで起動
2. 左の一覧でマクロを選ぶか、[新規作成]
3. 右側で名前・起動前ウェイト・アクションを編集
4. [保存] で `config.json` に書き込み
5. [テスト実行] で、ウェイト秒数のあいだに入力先ウィンドウへフォーカスを移して確認

### コマンドラインで実行する

| コマンド | 意味 |
|---|---|
| `KeyAutomator.exe -1` | ID=1 のマクロを実行 |
| `KeyAutomator.exe -id 1` | 同上 |
| `KeyAutomator.exe -name "全選択＆コピー"` | 名前指定で実行 |

- 画面は出さず、設定のウェイト後にアクティブウィンドウへ入力します
- 成功時 Exit Code `0` / 失敗時 `1`（詳細は同階層の `error.log`）

### 設定ファイル

実行ファイルと同じフォルダの `config.json` を使います。  
初めて起動すると空の設定が作られます。サンプルは `config.sample.json` を参照してください。

## 単体 exe の入手方法

開発者向け手順で公開ビルドした成果物を使います。

1. `publish\KeyAutomator.exe`（または配布用 zip 内の exe）を任意フォルダへコピー
2. 必要なら同じフォルダに `config.json` を置く（無ければ起動時に生成）
3. exe 単体で起動可能です（自己完結型 / 単一ファイル）

詳しいビルド手順は [README_DEVELOPER.md](README_DEVELOPER.md) を参照してください。

## 注意事項

- 入力は「その時点でアクティブなウィンドウ」に送られます
- 管理者権限が必要なアプリへの入力は、本アプリも管理者として起動してください
- パスワード等を `config.json` に平文保存する場合は取り扱いに注意してください
